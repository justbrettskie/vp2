VITALPULSE FOR WINDOWS (PORTABLE)

HOW TO START
1. Extract the entire VitalPulse-Windows folder from the ZIP.
2. Double-click Start-VitalPulse.bat.
3. VitalPulse should open in your default web browser.
4. Keep the PowerShell window open while using the app. Close that window to stop it.

NOTES
- This is a Windows desktop-friendly wrapper around the web interface bundled inside your APK.
  It does not require an Android emulator.
- Your browser stores app data locally using browser storage. Use the app's Export option to make
  backups before clearing browser data or changing browsers.
- The APK's Android-only integrations (such as phone motion sensors or Android export bridge)
  cannot be reproduced by this wrapper and may be unavailable on Windows.
- AI features that require an external service or API may not work unless the original app has
  those services configured and reachable.
- This is a portable test build, not a signed installer or a native .EXE.
